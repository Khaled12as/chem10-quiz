# مسابقة الكيمياء التفاعلية – الصف العاشر

صفحة واحدة (HTML/CSS/JS) لأسئلة الكيمياء الموضوعية من كتاب الطالب — بدون أي مكتبات أو خادم.

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل خادمًا محليًا:

```powershell
npx serve .
```

## المحتوى

- أسئلة موضوعية من كتاب الطالب – الفصل الدراسي الأول
- تصحيح فوري مع شرح لكل إجابة
- عدّاد صح/خطأ ونتيجة نهائية بنسبة مئوية
- إمكانية كتابة اسم الطالب (اختياري)
